# PAHAD+ phone app

The native PAHAD+ app (Expo / React Native), package `org.pahad.plus`. It has no data of its own: everything comes from
the PAHAD website at `https://pahad.org/api/app/v1` (see `src/lib/plus/app-api.ts` and `src/app/api/app/v1` in the
website). Posts, accounts, E-Passes and payments follow exactly the same rules as on pahad.org/plus.

## Screens

- **Valley**: the feed, one post per screen (swipe up; double-tap to like), with Community / Following / For You,
  PAHAD's picks (⭐), hubs, brief types and search.
- **Discover**: spotlight videos, creators to follow, hubs, briefs, regions and a searchable grid.
- **Post**: photo from camera or gallery, hub-specific fields, native date pickers, E-Pass options.
- **Profile**: your posts, E-Passes, saved posts, identity QR, notifications and settings.
- Post details, public profiles, circulars, E-Pass with QR, gate check-in with the camera, Razorpay payments.

## Build

```bash
npm install
npm run build:android
```

This writes `dist/PAHAD-Plus.apk` (to install and test) and `dist/PAHAD-Plus.aab` (for Google Play), signed with
PAHAD's key from `C:\Users\<you>\pahad-apk` (or `PAHAD_KEY_DIR`). It needs Java 17 and the Android SDK.
Raise `android.versionCode` in `app.json` before each Play Store release.

Test against a local copy of the website from the Android emulator:

```bash
PAHAD_API_BASE=http://10.0.2.2:3006 npm run build:android
```

`android/` and `ios/` are generated by `expo prebuild` and are not committed.
